ARENA X Entertainment website upload

Upload these three files to the ROOT of your GitHub Pages repository:
- index.html
- styles.css
- arena-x-logo.jpg

Keep all three files together in the same folder. Do not upload them inside another folder.

Then open your GitHub repository Settings > Pages and set:
Build and deployment: Deploy from a branch
Branch: main
Folder: /(root)
Save.

Your public website address will be https://YOUR-USERNAME.github.io/
